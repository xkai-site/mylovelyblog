# 上线验收清单

## 使用范围

这是当前站点的回归清单，不表示任何一轮修改已经验收通过。每次修改都应单独记录检查结果与未验证项，不能复用历史文档中的通过结论。

沿用现有 GitHub Pages 发布流程，不为验收更换构建工具或部署方式。仓库未包含工作流定义，部署入口和构建结果需在 Pages 设置及实际构建记录中确认。本地真实构建需要 Ruby／Jekyll；语法检查和临时预览不能替代真实构建。维护步骤见 [代码维护说明](maintenance.md)，过往前端验证见 [历史记录](frontend-redesign/verification.md)。

## 1. 发布与入口

- [ ] 检查 Git diff 和新增／删除文件，确认只有本次批准的变更，没有私密草稿或无关文件。首页、归档、分类、标签的源文件在 `pages/`。
- [ ] 仅在准备发布且已明确授权时，按平常方式提交和 push；核对该提交对应的构建、部署结果。只做本地维护时不要触发发布。
- [ ] 打开 https://xkai-site.github.io/mylovelyblog/ ，必要时强制刷新。页眉只保留导航与主题切换，首页显示近作、分类和标签；没有站名、组合 Logo、英文副标题、重复刊头或固定口号。首页文章摘要包含分类与标签，详情页标签在标题上方。
- [ ] 若工作流失败，保存失败步骤的日志；不要用“网页没更新”判断样式代码本身是否生效。

## 2. 先花五分钟检查这些

- [ ] 顶部依次打开「首页／分类／标签／归档」，链接始终保留 `/mylovelyblog/` 前缀，不出现 404。
- [ ] 页眉只有一个深浅色切换按钮：默认按系统外观打开，点击后切换并记住选择（刷新、跨标签页一致）；首次点击前系统外观变化仍会跟随。
- [ ] 在归档检索标题、标签或日期；清除条件后恢复全部文章。
- [ ] 打开《微服务项目快速入门》：标题、代码、配图可读；桌面目录点击能跳到对应小节。
- [ ] 打开《Agent调度策略选项》：表格、两张图片正常；文章显示标题保持原样，不因文件名不同而被改写。
- [ ] 打开《寻找》或《TradeOff》：短随笔没有空目录，不因为没有二级标题而报错。
- [ ] 分类页保留「技术／生活／随想」侧栏；分类页和标签页右侧不再显示重复分组标题及其分隔线。点击侧栏仅显示对应文章，当前项以强调色和加粗标示；切换后列表顶部对齐且无残留空白，字体、配色、列表结构和页面宽度不变。
- [ ] 点击文章分类、标签及 `Spring Cloud` 标签能直接选中正确分组；刷新、浏览器前进／后退和键盘 Enter 切换时，文章与侧栏选中状态保持同步。
- [ ] 归档包含本次构建应发布的全部文章。按实际 `_posts/*.md` 和构建日期核对数量，不使用历史记录中的固定篇数；未来日期的文章按 Jekyll 默认行为可能暂不发布。

## 3. 手机、键盘与长文

- [ ] 手机竖屏打开首页与技术文：导航可操作，正文无整页横向滚动，长代码和表格仅在自己的区域内滚动。
- [ ] 窄屏目录默认折叠，可以展开和点击；桌面目录在阅读时保持可用。
- [ ] 两种模式下白底图片都保留原颜色，不反色；有说明的独立图片显示图注。
- [ ] 浏览器放大到 200% 后内容仍可读，标题不被截断。
- [ ] 按 Tab 可看到焦点，能使用跳过导航链接、主导航、模式选择和目录；模式按钮支持键盘。
- [ ] 禁用 JavaScript 后，正文、图片、代码、分类和归档仍可用；目录／图注等增强允许消失，颜色仍跟随系统。
- [ ] 打印预览采用浅色正文，不打印导航和目录。

## 4. Typora 图片闭环（首次必须做）

1. 按 [写作指南](writing.md) 用命令生成一篇你准备发布的文章，或本地测试草稿。
2. 用 Typora 打开 `_drafts/<标识>.md`，粘贴一张截图。
3. 确认图片实际位于 `assets/images/<标识>/`，Markdown 中是 `/mylovelyblog/assets/images/...`，且 Typora 能显示。
4. 修改文章显示标题，确认图片目录、`slug` 和 `image_id` 不变。
5. 将准备正式发布的草稿按指南移至 `_posts/日期-标识.md`，连同图片一起提交、push；线上图片可见，归档与分类自动更新。

不要为了验收把无关测试文章或私密内容发布出去。本地试验用的草稿和图片可不提交。若 Typora 输出盘符路径、`file://` 或不符合规则的相对路径，先调整设置，不要靠线上 JavaScript 补救。

## 5. 内容与链接

- [ ] 随机核对旧文章的正文、标题、日期未被改写；旧图片无缺失。
- [ ] 如果收藏过旧文章，打开旧链接核对。分类不会再进入文章 URL；旧网址是否完全一致以本次线上核对为准。
- [ ] 没有标签、没有摘要的文章仍能阅读；无分类文章进入「未分类」分组。
- [ ] 文档、模板、脚本、计划和草稿不出现在网站页面列表。注意：公开仓库里的源文件仍公开，未发布文章的图片也可能作为静态资源部署。

## 可选：排版样例

如需检查引用、脚注、长表格等，可在本地草稿中使用以下内容。不要直接改旧文章正文作为测试。

````markdown
## 一节笔记

普通段落，**重点**、*补充说明*与 `inline_code`。

> 一段引用。好的排版不应打断阅读。

- 一项观察
- 另一项观察

### 一段代码

```yaml
service:
  name: example
  timeout: 3000
```

| 主题 | 观察 |
| --- | --- |
| 阅读 | 清晰且克制 |

一个带脚注的结论。[^note]

[^note]: 补充说明。
````

如有问题，反馈「页面地址 + 浅／深模式 + 手机／电脑 + 截图」，构建失败则反馈工作流日志，便于定位。

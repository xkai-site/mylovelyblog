# 调研记录

- 项目为 Jekyll 静态博客，工作区初始干净。
- 用户强调现有文章、图片、分类和标签组织已经完善，改动严格限于前端呈现。
- 设计方向：学术期刊式个人博客，避免卡片堆叠、装饰性渐变和 SaaS 式布局。
- 已有三态主题（系统／浅色／深色）、持久化与跨页同步，保留该机制并改进显式控制。
- 已有正文目录、图片题注、表格横向滚动与打印样式；保留这些阅读增强。
- 当前不协调处：全站大量无衬线 UI、宣传式首页 hero、分类方框按钮，正文标题与衬线正文割裂。将采用纸白／墨黑、朱砂强调、书刊式刊头与目录编排统一。

- 已查看桌面正文和深色手机归档截图，论文式正文、原色图片、图注与侧栏目录一致；移动目录折叠／展开／跳转和打印白底、隐藏导航均通过。

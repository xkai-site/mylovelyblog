# 前端重构与验证

## 设计与范围

- 私人文集／学术期刊方向：纸白、暖黑、朱红强调，衬线标题、细线目录与克制留白。
- 保留原有 Georgia／宋体正文、字号及行距，补充 Windows 宋体回退；正文标题、表格和题注统一到书刊排版。
- 首页直接进入近作目录及分类／标签侧栏；页眉只保留导航和主题切换，不再显示站名、组合 Logo、重复刊头、英文副标题、装饰编号、口号和重复计数。分类和标签页保留可跳转目录。
- 首页文章摘要同时展示分类和标签；详情页标签位于日期／分类下方、标题上方，文末不再重复显示。已针对首页、详情页和标签锚点验证，320/390/1440px 无横向溢出。
- 归档仅在跨多年时显示年份导航；搜索结果数量只在有检索条件时出现。
- 浅色／深色／系统三个直接可见的主题按钮；沿用原存储键与系统偏好机制。
- 归档可按标题、分类、标签、日期检索，支持空格分隔多个条件、全角字符、清除与 Escape。日期支持 `2026-04-24` 和页面显示的 `2026.04.24`。
- 没有修改文章、图片、元数据、内容组织、写作工具、Jekyll 配置或部署流程；没有新运行时依赖、远程字体或服务。
